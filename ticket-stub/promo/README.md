# 帧藏 · 小红书推广物料（3:4）

## 文件

| 文件 | 用途 |
| --- | --- |
| `out/framezang-xhs-3x4.mp4` | 成片：1080×1440，18 秒，30fps，H.264，无音轨 |
| `out/cover-3x4.jpg` | 封面：从成片尾帧导出，1080×1440 |
| `xhs-video.html` | 动画源码（按时间线逐帧渲染，可改文案后重出片） |
| `build-video.mjs` | 渲染脚本：`node promo/build-video.mjs` |
| `capture.mjs` | 从本地 web 版抓真实界面截图与票根 PNG |

## 标题备选

1. 把照片做成一张电影票根，只要三步
2. 用完的电影票别扔，我用照片重做了一张
3. 175 款票根模板，把旅行和电影都收进一张票

## 正文

看完的电影、坐过的航班、听过的现场，票根总是留不住。

做了个小工具「帧藏」：上传一张照片，选一个票根样式，改几行字，直接导出高清 PNG。

电影票、登机牌、音乐节票、邮票、明信片……175 款模板，27 种纸感与光效，照片的位置和缩放都能自己调。纯本地处理，离线也能用，做完存相册就能发。

视频里出现的票根，都是用手机里随手拍的照片做的。

## 发布建议

- 尺寸选 3:4，封面用 `cover-3x4.jpg`；标题控制在 20 字内。
- 成片没有音轨，发布时在平台里选一首轻爵士 / lofi / 钢琴，音量 30% 左右即可。
- 结尾的「点击下方小工具即可体验」是给挂在小工具详情页里的场景用的；如果单独当笔记发，把这一句换成「小红书搜索『帧藏』」再重出片。
- 前 3 秒是「照片变票根」的钩子，正文第一行也建议直接抛结果。
- 票根 PNG 是透明底（`capture.mjs` 里先清掉舞台底色再截图），换浅色背景时咬口和圆角会自然透出底色，不要用旧的带底色版本。

## 重出片

修改 `xhs-video.html` 里的文案或时间点后：

```bash
node promo/capture.mjs        # 需要重新抓界面截图时
node promo/build-video.mjs    # → promo/out/framezang-xhs-3x4.mp4 + cover-3x4.png
```

素材依赖：`promo/assets/` 下的票根 PNG 与界面截图，均来自 `ticket-stub` 本地 web 版实拍。
