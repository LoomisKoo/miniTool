# 帧藏 iOS

原生 SwiftUI 版本，位于 `ticket-stub/ios/Frame藏/`。

当前已建立：

- 票根模板选择：电影票、旅行票、演唱会票、漫游、邮票
- 主编辑画布与拖动 3D 悬停预览
- 票面信息编辑
- 系统相册选图与移除照片
- 照片、纸感、印章等特效开关
- 画板背景选择
- 保存到本机作品列表
- 作品档案：搜索、标签、备注、收藏与年度合集
- Pro 自定义模板：保存当前版式、照片、特效与配色
- 导出到相册、文件与系统分享
- Pro 超高清、透明背景与年度合集海报导出
- 发布文案分享

数据只写入本机，不使用 iCloud。

用 Xcode 打开 `Frame藏/Frame藏.xcodeproj`，选择 iPhone 模拟器或真机运行。
