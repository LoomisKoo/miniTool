# 本草

药材图鉴 + 药圃经营 + 坐堂看病。离线单页 H5，纯前端，`localStorage` 存档。

## 定位

**种药、采药、看病、记图鉴。** 药材有限且要生产，图鉴记录你的认知成长，看病是验证认知的关卡。

不做付费抽卡：随机性放在「山林采药」与「脚夫远行」里——随机决定你碰到什么机会，不决定你能不能得到。

## 玩法闭环

```
集市买种 / 山林采药 / 脚夫远行
        ↓
药圃种下（现实时间成熟，离线可累积）
        ↓
收药入库 → 图鉴「初识」（图、性味、归经、产地）
        ↓
出诊：四诊（文字）→ 辨证 → 选药开方 → 四档结算
        ↓
诊金 + 酬金 → 声望 → 解锁更多产区
        ↓
图鉴「通」「精」：用过、用对过才算真会
```

## 判定：按标签命中，不比对标准方

- `effects.js` 里有一套 **功效词表**（37 个）和 **病机 → 期望功效映射**（约 30 条）
- 每个证型挂 2~4 个病机标签，每味药挂若干功效标签
- 开方 = 逐个病机看「方中有无一味药能应」，命中任一对应功效即算覆盖

| 项 | 分值 |
| --- | --- |
| 证型正确 | 40 |
| 病机覆盖（覆盖病机数 / 病机总数） | 25 |
| 君臣佐使（指定君药 + 无配伍禁忌） | 15 |
| 炮制形态契合 | 10 |
| 药味精简（3~6 味满分，1 味 2 分、2 味 5 分、7~8 味 6 分、>8 味 3 分） | 10 |
| 成方对症（组成与某方全同且证型相符） | 5 |
| **十八反十九畏** | **一票否决 → 加重** |

四档：显效 ≥85 / 好转 ≥62 / 无效 <62 / 加重（踩禁忌）。
**无效不判失败**，病人三日后再来；诊金保底，让玩家变穷但不困死。

## 药方：常用方 37 + 秘方 11

**常用方**：集齐组成药材（图鉴「初识」）即自动解锁。
**秘方**：药材集齐也换不来，只能在脚夫远行时有两成机会偶遇孤本。

- **开方页一键套用**：组成药材都有货时出现「成方」快捷按钮；缺生品会自动用炮制品顶上
- **成方对症** +5 分、声望 +1；组成相同而证型不符会提示「不对此证」
- 图鉴 → 药方页分两张清单，未得的秘方显示为「未得秘方」，只露主治证型

药方只提供「更好」，不提供「能否」——没有药方也能看病，只是少一点加成。

## 炮制（同一味药的第二种人格）

31 味药带炮制形态，换制法即换药性：甘草生用清热、蜜炙补中；当归生用补血、酒炒活血。

| 辅料 | 用法 | 价 |
| --- | --- | --- |
| 蜂蜜 | 蜜炙，补虚缓性 | 30 |
| 黄酒 | 酒炙，引药上行活血 | 25 |
| 米醋 | 醋炙，入肝收敛止痛 | 20 |
| 食盐 | 盐炙，下行入肾 | 15 |
| 姜汁 | 姜制，减毒止呕 | 20 |

- 规则：**1 份生品 + 1 份辅料 → 1 份炮制品**；无辅料的（九蒸九晒之类）改耗 2 份生品
- 辅料来源：药圃集市买、远行带回
- 炮制品与生品在开方列表里**并列可选**，药性是另算的
- 亲手炮制过一味药，图鉴立即升「通」

## 防卡死

1. **动态病例**：病人按你当前药柜的能力生成，永远不超纲
2. **可婉拒**：少赚一笔，不判失败
3. **诊金保底**：治不好也给
4. **复诊**：无效或加重的病人进待诊队列，下次进门时标「复诊 · 第 n 次」，并给出「上次未及：湿、痰」这类线索
5. **图鉴不看抽卡**：种下/采到/买到即点亮

## 弟子（减负，不做养成）

最多 3 人，按声望 8 / 18 / 30 解锁，用钱收（240 / 420 / 680 文）。
每日代诊小病，隔天结算固定收入 26 文/人。不做等级、技能、成长树。

## 四诊与舌象

望诊带一张 **SVG 程序生成的舌象**，无图片资源。从证型的舌象文本解析参数：

- 舌质 5 种：淡 / 淡红 / 红 / 绛 / 紫（含淡暗、紫暗）
- 舌苔：白 / 黄 / 无苔（少苔、剥苔）
- 苔质：薄 / 中 / 厚腻，另叠加燥裂、润滑、胖大齿痕、瘦薄
- 望诊文本里没有「舌」字（如跌打肿痛）则不画舌

## 图鉴三种读法（同一份数据）

| 视图 | 看什么 |
| --- | --- |
| 功效 | 按首个功效分组的全部药材 |
| 产地 | 十一大区风土 + 本地药材 + 已识进度 + 道地标记 |
| 药方 | 37 首常用方（集齐即解锁）+ 11 首秘方（远行偶遇） |

## 数据

| 文件 | 内容 |
| --- | --- |
| `effects.js` | 功效词表、病机映射、十八反十九畏、评分常量 |
| `syndromes.js` | 40 证型（8 族 × 5），含病机标签与四诊文本 |
| `herbs.js` | 145 味药材：性味归经、功效标签、产区、炮制形态、生长档位 |
| `preps.js` | 5 种辅料 + 25 条追加炮制形态（原表已有者去重） |
| `formulas.js` | 48 首药方（37 常用 + 11 秘方）：组成、主治证型、方解 |
| `regions.js` | 十一大区（道地产区），含解锁声望与特产 |

药材数量 = 图鉴条目数量，无「只能看不能用」的条目。

## 开发

```bash
open index.html          # 直接跑，无构建
node build.mjs           # 打包三平台
node build.mjs xiaohongshu
```

产物：`dist/{douyin|kuaishou|xiaohongshu}-bencao.zip`

### 调试提速

`app.js` 顶部 `TIME_SCALE = 1`，改成 `0.02` 则一切生长/远行都约 50 倍速。

## 调试

`window.__bencao` 暴露了存档与主要动作（`state` / `availableItems` / `doPrep` / `judge` / …），
方便在控制台手动验证，也供 `node` 冒烟测试直接调用。
