# 爆红书

模拟爆红，看笔记从零涨到爆。

离线 H5：假社区、假流量、假私信，刷新即重开。源码目前在单文件 `index.html`。

## 上架信息

| 项 | 内容 |
| --- | --- |
| 名称 | 爆红书 |
| 简介 | 模拟爆红，看笔记从零涨到爆 |
| 图标 | `assets/icon.jpg`（512×512，上架列表用，不打进 zip） |

## 平台顶部适配（小红书 vs 快手）

顶部分两段，单独打包时在 `build.mjs` 里按平台覆盖 CSS 变量：

| | 小红书 | 快手 |
| --- | --- | --- |
| `--safe-t` 手机安全区 | 保留 `env(safe-area-inset-top)` | `0` |
| `--nav-h` 容器导航 | `44px` | `0` |
| `--xhs-nav` | `safe-t + nav-h` | `0` |
| 一级页标题（首页 / 发现 / 消息） | 容器导航显示；页内可做等高占位 | **不展示**页内标题 |
| 消息 / 我的顶留白 | 由 `--xhs-nav` 顶开 | 消息 `15px`，我的约 `36px` |

源码默认按小红书写；快手差异只写在 `build.mjs` 的 `platformCss`，不要在运行时嗅探 UA。

通用规范见 [xiaohongshu/guidelines.md](../xiaohongshu/guidelines.md#顶部安全区必遵)。

## 图标 Prompt

休闲手游应用图标：主体少、背景干净，要看出「正在爆」。**画布/卡片直角，不要圆角外框。** 爱心和特效要圆润，不要尖角。可用轻微立体高光。缩到 64px 仍能认。不要海报文案、不要整屏 App 截图。

**方案 A — 无字（推荐）**

```
手机游戏应用图标，正方形 1:1，1024 像素。画布直角，不要圆角外框。极简休闲游戏图标，带一点立体：中央一张直角米白小卡片，轻微厚度、顶部高光、底部短投影。卡片上有一颗品牌红 #FF2442 爱心：饱满圆润，像软糖或气球，两端圆钝，不要尖尖的心形、不要锐角。爱心旁两三道圆头小射线或圆点碎光，表示刚爆红；特效全部圆润，不要尖刺、不要星芒尖角、不要锐利碎片。装饰极少：最多再加一两颗很小的圆润红心，不要眼睛，不要粒子雨，不要满屏爱心往外炸。深色纯底，四周留约 15% 空边。无文字、无中文、无 Logo、无水印。
```

**方案 B — 有短名**

```
手机游戏应用图标，正方形 1:1，1024 像素。画布直角，不要圆角外框。中央一张直角米白小卡片，轻微立体厚度和高光。一颗圆润软糖感红心，加两三道圆头小射线。不要尖心、不要星芒尖角。深炭灰纯背景。底部可加很小的粗字：只写「爆」，或最多「爆红书」三字。不要眼睛、不要粒子雨、不要满屏特效、不要口号、不要海报构图、不要水印。
```

生成后裁成正方形，主体居中。有字版如果糊成一团，改用无字版。

## 封面海报 Prompt（竖屏 3:4）

宣传海报，不是图标拉大。上中下分区：上氛围、中产品画面、下标题。文案必须画进图里（或后期用字体叠，但构图要给字留空）。

**文案（定稿，海报上要用）**

- 主标题：爆红书
- 副标题：模拟爆红，看笔记从零涨到爆
- 角标（可选）：刷新重开

**方案 A — 信息流爆掉（推荐）**

```
竖版游戏宣传海报，比例 3:4，1080×1440。休闲手游主视觉，Q 版卡通插画风也可以，手机不必写实渲染，做成圆润玩具感、简化屏幕即可。不是应用图标，不是 1:1 裁切，不要把方图标放大当海报。中下部一部风格化小手机，屏幕里是生活笔记九宫格信息流（不要真实品牌界面）。爆红要有，但克制：从屏幕升起少量圆润红心、两三个圆角数字、一两朵圆头碎光，像刚爆开，不要眼睛，不要粒子雨，不要满屏爱心潮。爱心和特效全部圆润软糖感，不要尖心、不要星芒尖角。品牌红 #FF2442，夜色背景 #141018，淡红光。画面下三分之一留大块空位给中文标题。图上要有字：超大主标题「爆红书」，副标题「模拟爆红，看笔记从零涨到爆」，小角标「刷新重开」。干净粗圆体中文，白字加点红。不要英文、不要水印、不要应用商店边框。
```

**方案 B — 人被流量淹没**

```
竖版 3:4 游戏海报，1080×1440。Q 版卡通插画也可以，人物和手机都不必写实。一个风格化小年轻人拿着玩具感小手机，很开心。屏幕里有克制的爆红：几颗圆润红心和两三个数字往上飘，不要眼睛，不要潮水般特效。爱心和光效圆润，不要尖角。轻微立体高光，品牌红 #FF2442。底部约 28% 留深色干净区域给标题：「爆红书」/「模拟爆红，看笔记从零涨到爆」。不是方图标。不要水印。
```

生成后若 AI 把字写残，用无字底图 + 本地字体叠这三行，成品仍要 3:4，放到 `covers/爆红书_封面.png`。
