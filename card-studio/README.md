# 卡造 · Card Studio

给个人 DIY 用的名片 / 证件 / 吊牌生成器。纯 HTML + CSS + JavaScript，**全程本地处理**：图片和文字都不上传，导出的 PNG 可直接送印或发社交平台。

## 十个玩法分类

| 分类 | 模板 |
| --- | --- |
| 名片 | 社交名片、宠物名片、游戏名片、开发者名片、摄影师名片、音乐人名片 |
| 主页 | 代码资料卡（横版编辑器 + 贡献热力图）、霓虹主页卡、主页名片、NFC 碰一碰卡 |
| 人设 | 朋友圈人设、MBTI 卡、今日玄学、今日状态牌、摸鱼许可证、牛马证、单身认证、熬夜冠军、剧本杀角色卡、好人卡、精神状态鉴定书、欠条 |
| 搭子 | 搭子卡、生日邀请卡、宿舍床位牌、社团成员卡、游戏 ID 卡、加我卡 |
| 恋爱 | 恋爱契约、恋爱天数（自动算天数）、异地恋时区卡 |
| 追星 | 追星小卡、出道卡、应援手幅 |
| 毛孩子 | 宠物牌、猫主子身份证、铲屎官证、人类幼崽档案、宠物工时表 |
| 证件 | 挂绳工牌、学生证 |
| 异世界 | 魔法学院录取通知、魔法学院学生证、英雄注册卡、平行宇宙通行证、特工档案卡、星际舰队船员证、集换式战力卡 |
| 周边 | 贴纸卡、谷子吊牌、音乐节纪念卡、行李牌、电影票根 |

53 套模板，49 套带独立设计的背面，支持 3D 翻面预览。整体走 Y2K 贴纸拼贴的视觉，文案偏自嘲、玩梗和社交传播，不做正式商务名片那一套。

## 能力

- **尺寸按 mm 定义**：名片 90×54、CR80 85.6×54、宠物牌 Ø38、常见竖版吊牌等，画布按比例渲染
- **照片 / Logo 本地上传**，自动压到 1000px，透明圆角导出
- **二维码本地生成**：vCard 名片、网址、自定义文字三种内容
- **配色替换**：整套主色可换（荧光绿 / 莓果粉 / 电紫 / 橘子汽水 / 泳池蓝 / 墨黑）
- **没有晒图底和背景板**：所见即所得，舞台上是什么样，导出的 PNG 就是什么样
- **导出**：只导出卡片本体，标准 / 超清两档，透明圆角，无背景和投影
- **离线**：字体、二维码、导出库全部固化在 `vendor/`，无任何 CDN

## 本地预览

```bash
npx serve card-studio
```

## 打包上架

```bash
node build.mjs                 # → dist/xiaohongshu-card-studio.zip
```

产物为单个经典脚本 + 内联样式，经 `xiaohongshu/minitool-zip-builder` 审计后压包。

## 文件

```text
card-studio/
├── index.html              # 预览页（<body> 同时是打包页面结构）
├── src/templates.js        # 53 套模板：尺寸、字段、示例值、正反面 HTML
├── src/app.js              # 渲染、表单、二维码、图片、导出
├── src/style.css           # 工具界面样式
├── src/cards.css           # 卡片通用规则与 53 套版式
├── vendor/                 # 字体、qrcode、html-to-image、lucide
├── assets/icon.svg
├── platforms/xiaohongshu/  # 平台标题 / 顶栏适配
└── build.mjs
```

## 设计约定

- 模板只声明「可用字段 + 锁死的版式」，不做自由拖拽画布；填几个字就能出图
- 卡片内部所有尺寸用 `em`，基础字号由 `--mm` 推导，换尺寸时版式等比缩放
- 新增模板：在 `templates.js` 注册一个对象（`id / cat / w / h / shape / fields / demo / front / back`），在 `cards.css` 补一组 `.t-<id>` 样式即可
