# 观影座舱

移动端电影院观感模拟小工具。

当前版本包含：

- 普通激光厅、激光巨幕厅、三面环景厅三种轻量伪 3D 影厅
- 按影厅规模动态生成的买票式完整选座面板
- 不同影厅使用不同排数与每排座位数量，后排座位更多
- WebGL 第一视角观看银幕，摄像机位于所选座位眼睛高度
- 真实的影厅地面、墙面、银幕、椅背、扶手与逐排升高的座台
- 位置视角、沉浸感、字幕舒适度的综合评分
- 标准 / 轻度 / 中度 / 高度视觉模糊模拟
- 左右声道试听
- 抽象光影样片占位

构建小红书离线包：

```bash
node build.mjs xiaohongshu
```

产物位于 `dist/xiaohongshu-cinema-seat.zip`。
