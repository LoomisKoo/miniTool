# 2026-09-08 工作日志

## 新 miniTool 立项：祈愿灯（kongming-deng）
用户想做一个许愿小工具：输入/预选祝福语 → 贴在孔明灯放飞 → 背景是灯海+烟花+人群的「繁华盛世」夜景，可配乐、可分享。

### 已确认的规格（讨论定稿，待用户「开始」后执行）
- 渲染：**3D 程序化（Three.js）**，孔明灯/烟花全程序生成，**不需要外部 3D 模型、不需要贴图**；背景远山/城郭/人群剪影用 CanvasTexture 程序绘制。
- 平台：**移动端 H5 单页**，独立 miniTool，不联网不存档。
- 配乐：**国风治愈**（需无版权 mp3/ogg，由我找免版权曲库放入 assets）。
- 互动：**美化 textarea**（中文输入必需，隐藏原生边框+玻璃容器）+ 预选 chip；放飞后孔明灯升空汇入灯海。
- 分享：**canvas→PNG 许愿卡**（复用 xingkong-jump 的 buildExport().toDataURL + 下载链路）。
- 复用：xingkong-jump 的 `vendor/three.min.js`（本地化离线）、viewport-fit=cover + safe-area、静音切换按钮模式。

### 技术要点
- 文件结构镜像 xingkong-jump：index.html + src/{style.css,app.js,lantern.js,fireworks.js,background.js,wish.js,export.js,audio.js} + vendor/three.min.js + assets/。
- 性能：灯 40–80 盏、烟花粒子加 AdditiveBlending + depthWrite:false、RAF 节流。
- 中文输入无法纯自定义，必须 textarea（已与用户确认接受）。

## 第十一轮（17:02，烟花音效 + 远近差异）
- `KD.audio.pop(dist)`：WebAudio 合成「噼啪」声，由 dist（到相机距离）映射远近：
  - 振幅 `0.55 * (1-d)^1.35 + 0.025`（近 = 响，远 = 弱）。
  - 主爆音用带通噪声，带宽中心 `4200*(1-d)+520` Hz（近 = 清脆明亮，远 = 沉闷）。
  - 低频 thump 频率随距离下降（远处更沉）+ 3 个延迟的小噼啪尾音。
  - 远 = `d*0.48s` 声传播延迟（用 setTimeout 触发），强化距离感。
- `fireworks.burst()` 每次炸开时算出到 `KD.fireworks.camera` 的距离调用 `pop`；app.init 注入 `KD.fireworks.camera`。
- 静音/未启动音频时直接 return（不创建节点）。
