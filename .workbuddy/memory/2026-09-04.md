## 第三轮：两个真 bug（同日）

1. **`[hidden]` 属性集体失效** —— 根因值得记住：给元素设了 `display:flex` / `inline-flex` 的作者样式，优先级高于 UA 样式表的 `[hidden]{display:none}`，于是 JS 里的 `el.hidden = true` 完全不起作用。
   受影响的有 `.thumb-x`（清除按钮）、`.bg-wrap`（图片背景区）、`.dots-row`（色板行）——纯色模式下图片上传区会一直显示。
   修法：加全局兜底 `[hidden] { display: none !important; }`。**以后写组件样式时，凡是带 hidden 切换的元素，都别在基础类里写 display，或用这条兜底。**

2. **中心 Logo 被拉变形** —— `renderCode()` 里用 `ctx.drawImage(img, x, y, w, h)` 把 logo 硬拉进正方形区域，非正方形图会被压扁/拉长。
   修法：新增 `containDraw(ctx, img, x, y, w, h)` 等比缩放 + 居中绘制，画在原有的圆角 clip 区内，露出的是底色衬垫。预览和导出 PNG 共用 `renderCode`，一次修复两处。

**用户偏好补充**：明确要求「不需要验证和测试」时，改完直接构建 + 刷新预览即可，不要跑冒烟脚本。

   - 收起前要先把 `max-height` 从 `''` 写成具体 px 值才能过渡（`auto` 不可过渡）。
