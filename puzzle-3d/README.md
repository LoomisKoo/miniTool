# 3D 拼图工作台

上传图片，按自定义行列切割成拼图块，在 Three.js 场景中以真 3D（厚度 + 光影 + 阴影）预览。

## 本地预览

```bash
cd puzzle-3d
python3 -m http.server 8765
# 打开 http://127.0.0.1:8765
```

## 能力

- 自定义列 × 行（单边 ≤ 50，总块数 ≤ 1600）
- 滚轮缩放 / 拖拽旋转 / 右键平移（大拼图可缩到全局再放大）
- 左侧待选区点选拼块，点击场景放置到正确格位
- 「打散」「拼好」快速切换散落堆与完整预览

## 说明

成百上千块时纹理会自动降采样，超过约 300 块改用盒体几何以保流畅；阴影在过高块数时会酌情关闭投射。
