# 仙鹿起名（naming）

按性格 / 生辰取名字：中文名、英文名，以及外文名转中文名。纯离线 H5（单文件产物、无外链、无网络请求、无 iframe）。

**核心设计：题量决定的是「尺子的精度」，不是「能出多少个结果」。**
8 道题 → 一个 7 维性格向量；库里每个名字 → 同样 7 维（由组成它的字合成）；两者算相似度 → 全库排序 → 前 N 名都说得通，再从中采样制造手感。所以题库小不影响结果丰富度。

## 玩法（第一版）

1. **测性格取名** — 首页主 CTA。8 题（6 题人格 + 2 题直球偏好）→ 一组「姓 + 名」推荐 → 点开看字义 / 读感 / 性格对照 / 分享卡片。详情页可标「不喜欢这个名字」、对单字「排除 / 保留」，下次推荐会跟着过滤。
2. **生辰起名** — 输入公历生日（时辰可选）→ 本地排四柱八字 → 统计五行缺补 → 宜补五行给取名加权。可与性格测试叠用（结果页「加生辰」）。不做大运流年；文案标明传统文化参考，不代表科学结论。
3. **备选名**（浮层）— 顶部两排筛选（性别 / 常见度）钉在浮层顶部不跟列表滚，下面按排序的全量列表，点任意一条直接切为主名。
4. **外国名转中文名** — 输入 `Emma Wilson`，给的是**正常的中文名**（如「杨见山」「尉迟恺」），不是音译。姓照原名的音头配（g → 顾 / 郭 / 葛 / 高），名完全走取名那一套（意象域 + 性格向量 + 读感），只把「音色别离原名太远」当小加分项；单姓配两字名、复姓配一字名，落在两三个字里。音译写法（威尔逊 / 格蕾丝）只作为附注给证件用。
5. **中→英** — 同一份性格在英文名池里对照，给来源含义 / 年代感 / 昵称链。中文名那一栏**边输边配**，不需要点生成按钮。筛选条上方显示当前条件摘要，可一键清除。
6. **跨文化对照** — 结果页顺带显示「同一个你，换个文化叫什么」。
   名字详情页四条操作固定成两行两列（换名 / 备选名 / 收藏 / 选姓氏），文案长短不影响版式。
7. **名字工作台** — 台面上只有「姓」「名」两行，点哪行进哪页：选姓页 308 个姓（类型 / 常见度 / 首字母三组筛选），选字页 1235 个字（意象域 / 性别 / 常用度 / 首字母四组筛选）。**筛选全为「全部」时列出全部候选，不做截断**；有筛选时显示「已筛选」摘要与清除按钮。选字不限于两字：一个字（提示重名率高）、两个字、三个字以上（提示非主流）都能收藏。
8. **我的** — 两个 tab 之一（另一个是首页）：性格画像、生辰卡、推荐偏好摘要、收藏列表（带来源）、本机数据说明与清除入口。
9. **分享卡片** — canvas 竖版 3:4（900×1200）。导出走弹层内的「下载图片」按钮（保存中有状态提示）。
10. **名人同字/同名** — `celebrities.js` + `celebrities-more.js` + `celebrities-more2.js` 合计约 **700+** 条古今中外人物（中外并重，纯文字、无图无外链，约 115KB）。名字详情与自选预览会显示「同名 / 同字」参考与两三段成就简介；仅作文化联想。

**关键设计**
- **字是原子**：只标 1235 个字（各卷原始条目 1985 条，`engine.js` 开头统一去重），就能生成十万量级的双字组合。标全名标不过来，标字标得过来。
- **两套字池分开**：取名用字讲意象（澈 / 谦 / 瑾），音译用字只为读音（玛 / 蒂 / 尼）。混在一起会拼出「李尼蒂」这种东西。
- **精选名整体排在拼装名前**：`tier` 字段保证推荐靠前的都是真人用过的名字，长尾才交给算法。639 个精选名里约 600 个能通过校验出场。
- **精选名豁免意象域规则**：`validate` 的 `skipDomain` 只对拼装名生效——「诗涵」这种真名字不该被「字与字意象不搭」拦下。
- **人工译名豁免读感规则**：英文名库的 `zh` 是通行译名（Silas → 赛勒斯），常含字库外的常用字，走 `lite` 只查谐音黑名单。
- **英文名库是策选的常见名库，不是权威人口普查**：包含常见名字、中文姓氏罗马化及双语名人参考；名人条目用于文化联想，不宣称覆盖所有英语地区、年代或公众人物。
- **双语名人库不是搜索别名表**：每位人物保留英文全名、中文全名、可独立查找的英文 token、职业与短简介；token 会进入英文名池，但完整姓名不会伪装成一个 given name。
- **英文名按名字小写后去重**：各数据文件加载完成后运行时保留首次出现的记录，避免批次重叠影响筛选与匹配。
- **护栏优先于人味**：三声连读、声调全同、音节重复、意象域打架、负面谐音、整名拼音撞词、名里出现姓氏本字，任一条命中直接淘汰。
- **复姓走同一套护栏**：`surSyls()` 把单姓 / 复姓统一成音节数组，读感、校验、拼音显示都从这一个口子取；复姓按音节数摊平音感向量，否则它永远被算成「最有性格」的姓。
- **外文名不音译**：`NM.chineseName()` 姓氏按音头匹配（含复姓），名字直接复用 `namesForSurname` 的整套校验，只加 0.13 权重的音色贴近分。音色是点缀，不是目标。
- **`topChars` 带缓存**：它要扫全字库逐字算余弦，而 `recommend` / `chineseName` 会对几十个姓各调一次 `rankNames`。同一 profile 下结果相同，不缓存就白算上百遍。
- **底栏固定**：页面级操作按钮统一由 `dockFor(screen)` 渲染进 `#dock`，不写在内容末尾；选字页的「已选」也挂在底栏里，选字只改底栏和那一个格子，页面内容不重画、不位移。
- **选姓氏 / 备选名都是浮层，不是页面**：这两个都是「给当前这一页换一个选择」，所以做成 `#sheet` 底部浮层，选完就地重排，不往页面栈里插页。打开 / 关闭都有动画（上滑进入、下滑退出，退出动画走完才真正 `hidden`；`prefers-reduced-motion` 下直接切换）。头部标题绝对定位居中（不受右侧「关闭」宽度影响），一次只显示一种内容，所以没有二级视图、也没有浮层内返回键。从结果页打开选姓是唯一例外——结果页列的是「姓 + 名」组合、本身不认单一姓氏，所以选完在同一个浮层里换成该姓的候选名；从那里挑一个才进详情（此时才 push 结果页）。换姓从原来的「推两页再退回」变成原地一步。
- **浮层正文和整页同一套排版**：`.sheet-body` 也是 flex 列 + `gap: 14px`，所以模块间距和页面一致；筛选 / 搜索那一栏包在 `.sheet-search` 里，`position: sticky; top: 0` 钉在浮层顶部，列表滚它不滚（负 margin 把底色铺到 padding 外，盖住滚上来的内容）。
- **关闭浮层时返回键先收浮层**（浮层没进栈，不该连带弹掉上一页）；`Esc` 也收浮层。
- **返回键跟页面栈**：`hist` 记上一页，`go()` 压栈、返回键弹栈，`finishQuiz()` 走 `go('result', true)` 顶掉答题页。进详情之前那一页才回得对（静态映射表只能退回推荐板，会一下跳回两页之前）。栈空时（刷新后直接落在某页）退回静态映射表兜底。
- **「浏览名字」是一个区域**：详情页和备选名是同一个区域里的两个视图，来回点只是换数据（换一个名字 / 换一批候选），不是深入一层。备选名做成浮层后，来回点完全不动页面栈；在浮层里挑 6 次名字，按一次返回就退回进详情之前那一页。
- **返回键跟页面栈**：`hist` 记上一页，`go()` 压栈、返回键弹栈，`finishQuiz()` 走 `go('result', true)` 顶掉答题页。进浏览区之前那一页才回得对（静态映射表只能退回推荐板，会一下跳回两页之前）。浮层开着时返回键先关浮层（浮层没进栈，不该连带弹掉上一页）。栈空时（刷新后直接落在某页）退回静态映射表兜底。
- **两个 tab**：`#tabbar` 只在「首页 / 我的」两个一级页面出现（子页面是压栈的，自动收起），选中的 tab 图标由描边换成实心。它永远贴屏幕最底（含安全区），操作底栏 / 回顶按钮 / toast 都用 `body.has-tabbar` 让上一层，互不压住。
- **英文名库跟着整页滚**：`#en-browse-list` 不再自带二级滚动区，筛完往下滑就是列表；滚过一屏后右下角浮出回顶按钮。
- **卡片一种版式**：`renderZh` / `renderEn` 共用同一套页脚和边框，各自的纵向分区不同。上半段（名字 / 拼音 / 一句话）压得很紧，省下来的高度都给内容区和雷达图；`CONTENT_BOTTOM` 是按雷达轴标签的上沿倒推出来的，改动这里要先想清楚会不会压到标签。

## 视觉语言

一套**可爱风（奶油马卡龙）**的体系（蜜桃粉强调色、奶油/纯白两档底色、暖棕墨色文字、大圆角、柔和粉调阴影、圆体字优先），界面和分享卡片共用同一组颜色，改的时候两边一起改（`card.js` 的 canvas 读不到 CSS 变量）：

| 变量 | 值 | 用途 |
| --- | --- | --- |
| `--bg` / `--surface` | `#fff7f2` / `#ffffff` | 奶油底、纯白卡片面 |
| `--ink` / `--ink-2` / `--ink-3` | `#4a3b36` / `#6b5852` / `#b09a92` | 暖棕文字三级 |
| `--accent` | `#f26d8d` | 蜜桃粉，唯一强调色：主按钮 / 印记 / 雷达图 / 链接（链接文字用更深的 `#e8557b`） |
| `--mint` / `--lemon` / `--sky` / `--lav` | 各自 `-soft` 浅底 | 首页入口图标的马卡龙圆徽（五色轮换） |
| `--ok` / `--warn` | `#3aa981` / `#e8823f` | 「读感没问题」「非主流」这类结论 |
| `--line` | `#f6e3d9` | 奶油发丝线 |
| `--fav-red` | `#f25468` | 只给「收藏」这一个动作；和 `--warn` 的橙刻意分开，别混用 |

- **字面只有一套**：圆体字优先（iOS 落幼圆 Yuanti SC，没有就退回苹方），标题 weight 600，正文 400，不用 500。
- **圆角只有四档**：卡片 22px、胶囊 15px、小格 11px、按钮/筛选/搜索框走 `9999px` 全胶囊。主按钮是粉渐变全胶囊 + 柔和粉阴影，按下 `scale(0.96)`。
- **印记是标识**：首页、分享卡片都有一枚蜜桃粉渐变的小圆章（`.seal` / `card.js` 的 `drawSeal`），不旋转、带一点软阴影，是全站唯一的品牌符号。
- **收藏是红色 toggle**：详情页的收藏胶囊没收藏时是实心红（`.pill.fav`，白字），收藏后回到普通胶囊色，再点一次取消收藏（同一颗按钮两态）。红的只给这一个动作。
- **结果页有雷达图**：`app.js` 的 `radarSvg()` 用内联 SVG 画七轴雷达（近黑 = 你的性格，蓝色 = 这个名字），不引任何图表库。本体默认 148px（手机宽度 375~430 定的），svg 盒子再往外留 `RADAR_PAD`：轴标签画在圆外，不留这一圈就会压到右边那列文字上。只画「你」的时候（结果页 / 「我的」的画像）走 `selfOnly`：不叠名字那条线，也不放「你 / 这个名字」的对照说明。
- **卡片颜色写死在 `card.js`**：canvas 读不到 CSS 变量，改配色时两处都要动。
- **尺寸按手机定，不做等比缩放**：`html` 基准 15px，正文 13~15px、辅助说明 11~12px；大字号只留给名字（`.name-big` 40px、`.rec-name` 20px）。字号有下限，缩的是留白、圆角和组件高度——等比缩放会把 9.5px 的辅助文字压到看不清。
- **横向一律满宽**：面向移动端，`.app` / `.dock` / `.tabbar` / `.sheet-panel` 都不设 `max-width`，任何屏宽下都撑满（桌面浏览器打开也是满宽，不再有 600px 手机框居中）。改版式时注意别给容器加回宽度上限。
- **换页有动画**：`go()` 走 `slideSwap()`——旧页滑出右侧，换完内容新页再从右边滑进来（`prefers-reduced-motion` 下自动关掉），换页本身有定时器兜底。**tab 之间是平级切换**（首页 ⇄ 我的），只换内容不推页。
- **回顶按钮**：滚过 420px 后右下角浮出圆形按钮（`.to-top`）；挑选姓/字页监听 `.grid-box` 滚动（不只 window），点后滚回列表顶；有底栏 / 选字页底栏更高时自动上抬。

## 打包与本地预览

```bash
node build.mjs                 # 全部平台
node build.mjs xiaohongshu     # 仅小红书
node serve.mjs                 # 本地预览 → http://127.0.0.1:9880/body.html
node serve.mjs 9000            # 换端口
```

预览用 `serve.mjs` 而不是 `python3 -m http.server`：后者不发 `Cache-Control`，浏览器会用启发式缓存把 `src/*.js`、`src/*.css` 攒着不重新拉，改完代码刷新看不出变化（看起来像「改动没生效」）；`serve.mjs` 一律 `no-store`。产品的单文件产物是经典 script，`file://` 直接打开也能跑，只是那样改源码同样要清缓存。

## 已知边界 / 下一步

- **外文名转中文名不再走音译**：`NM.chineseName()` 只把原名当「音头参考」用（`Grace` → g → 顾 / 郭 / 葛 / 高），名字本身完全由性格 + 意象域 + 读感决定，所以 2~3 字、有释义、能过谐音黑名单。代价是与原名的读音关联比音译弱——这是刻意的取舍。真要音译写法时，结果页底部仍给一条证件用的附注。
- **中→英的音近匹配较浅**：目前只用首音节 + 年代 + 性格，没有做「名字整体听感」。
- **详情页已支持「保留 / 排除字」**；工作台仍是手工自选。小红书 Storage 需真机验证；图标 / 上架素材 / 八字合规文案需产品侧确认。
- **姓氏 308 个**（单姓 257 + 复姓 51），常见与少见都覆盖到了；再往上扩就是确实罕见的姓，收益递减。
- **复姓只在几个入口出现**：自选姓氏页、名字工作台、外文名转中文。按性格推荐的推荐板仍是单姓——复姓只有两个字两个音节，混进去会把常见单姓挤掉。
- **人格轴里的 `rat`（理性/直觉）对姓氏几乎没区分度**：声母表里只有 `jqx` 一组带这个信号，所以姓氏气质标签靠的是「在全体姓氏里的相对位置」，不是绝对阈值——绝对阈值会让七成姓氏都判成「百搭」。
- **音译字池 198 个仍是「附注」用途**：只用来给证件写法（`NM.translitChars`）和英文名的通行译名兜底。非拉丁语系（日语、阿拉伯语、斯拉夫语）的转写质量不如英文，因为 `romanSyllables` 只为拉丁拼写调的规则；不过这不再影响主答案，主答案走 `NM.chineseName`。
- 卡片只有单人版，还没做「一家三口」「情侣对照」这类有内在关系的合集。
