# 06 · 城市重构（网格城市 + 1:1 建筑 + 里外配套）

本章是微光城区第二阶段的总纲：**扩城、换骨架、补齐城市该有的东西**。
风格参照「雨夜便利店」那个小场景的材质与灯光语言（三渲二质感的配色、霓虹层次、接地暗部、光池），
但**比例是 1:1**，且**不是微缩模型、不固定在雨夜**（天气可切换）。

开发方式：本文档逐项拆成勾选框，**做完一项勾一项**。勾选即代表该项已通过验收。

> **本阶段代码位置**（已完成项都在这里）
> - `city2/plan.js` 城市数据：路网、五级高差 `groundY()`、六片区、144 栋建筑、114 家店、招牌库、POI
> - `city2/kit.js` 顶点色合批 `MeshBuilder` + 三渲二渐变 `toonMap()` + 招牌文字贴图
> - `city2/world.js` 静态世界：地形/江面/路面/路缘/斑马线/楼体/亮暗窗/光池/街具/天桥/索道/摩天轮/工地
> - `city2/life.js` 动态：46 车 8 公交、90 行人、缆车、鸽子、猴群、落叶、随人雨幕
> - `city2/interior.js` 室内容器：便利店/面馆/办公楼/商场/地铁五种内景
> - `city2/main.js` 渲染与玩法：bloom、碰撞、WASD、E 进门、天气切换（1 夜 / 2 雨 / 3 昼）
> - 入口：`city2.html`（主页入口为「ENTRY 05」）

## 0. 核心决策（不要重新讨论）

| # | 决策 | 理由 |
|---|---|---|
| A | **正交网格 + 3~4 条斜街** | 放射路网切出锐角地块，无法排方正塔楼/南北通透板楼；且所有路径必须过中心，走两次就腻 |
| B | **环城路 = 四边形 + 四角大圆角（R≈120m）** | 圆环与网格全是斜交口，内侧弯月地块无法用；四角正好放立交/绿地 |
| C | **扩到 700×700m** | 现在 148m 见方里立 92m 的楼，比例必然读成模型。148m 只是真实城市的一个街区 |
| D | **城市不平** | 五级高差是消除模型感最有效的手段 |
| E | **CBD 主塔 320~350m** | 高度突变才真实；平滑渐变反而假 |
| F | **可进入门口有光效，按 E 进入**（沿用现有） | 玩家 3 秒内能学会的门语法 |
| G | **认领只限住宅房间** | 商铺里放张床是错的 |
| H | **靠近才加载内部** | 性能前提；设计上必须配合（见 §5） |
| I | **里外配套都要有** | 参照雨夜便利店：外面有售货机/垃圾桶，里面有货架/冷柜 |
| J | **设施密度分级 A/B/C** | 「每处都有细节」与性能同时成立的唯一办法 |

## 1. 骨架

### 1.1 规模与路网

- [x] 城市范围扩到 **700 × 700m**（约 49 公顷）
- [x] 步行穿城控制在约 8 分钟
- [x] 路网四级 + 巷子 + 步行街

| 等级 | 宽度 | 断面 | 间距 |
|---|---|---|---|
| 主干道 | 40m | 3 人行 + 3 非机动 + 11 车行（双向 6）+ 5 中央绿化带 + 11 车行 + 3 非机动 + 3 人行 | 350m |
| 次干道 | 24m | 3 人行 + 7.5 车行 ×2 + 3 人行 + 2 中央栏 | 175m |
| 支路 | 12m | 2.5 人行 + 7 车行 + 2.5 人行 | 90m |
| 巷子 | 5~7m | 无分离，水泥/青砖 | 30~50m |
| 步行街 | 15m | 全铺装，无车 | — |
| 环城路 | 30m | 四边形 + 四角 R≈120m 圆弧（北段压在 z = +210m，作为片区与山脚分界） | — |

- [ ] 基本街区（block）控制在 **90~120m 见方**
- [x] **斜街 3~4 条**穿透老城，产生三角地块与五岔/六岔路口
- [ ] 三角地块的处理：楔形楼 / 街角口袋公园 / 变电+停车
- [ ] 环城路四角放立交或绿地，外侧加防护林，**城市边缘不许突然消失**

### 1.2 地形：五级高差

- [x] 江面 **-8m**，江堤有台阶下到江滩（-6m）、防汛墙、闸口、下江坡道
- [x] 城市整体**向北缓抬 6m**（缓坡，不是台阶）
- [x] 北侧一座山，高差 **25~35m**
- [x] 山脚线在 **z ≈ +215m**（紧贴北侧环城路外侧），城内可利用山坡进深约 135m；山体在开发边界（z = +350m）之外继续延伸到 **z ≈ +400m 处的山脊**再回落，不允许在边界上被切平
- [x] 江面同理，在 z = −350m 边界外继续延伸约 50m 再交给雾/远景，两端用绿化与堤岸收口
- [ ] 山体等高线间距 10m，山脚做挡土墙 + 排水沟 + 山脚公园
- [x] 新住宅区比老城高 **3m**，用大台阶 + 挡土墙 + 无障碍坡道过渡
- [ ] 两处**下沉广场**（商场主入口前、地铁换乘站上方），各下沉 4~5m
- [x] 人行天桥 3 座（带雨棚、广告、楼梯/电梯）
- [ ] 一段高架（约 400m，带隔音屏）

### 1.3 上下山四条通道

- [x] **A CBD**（约 10 公顷）：写字楼 6~8 栋、大型商场、中央广场（60×80m）、地铁出入口 2~3 个、公交枢纽
- [x] **B 老城区**（约 12 公顷）：5~7 层砖混住宅、密集巷子、菜市场、小学+操场、社区卫生中心、派出所、便利店 3~4、早餐铺、快递驿站；电线杆最密
- [x] **C 新住宅区**（约 14 公顷）：3 个封闭小区（围墙+门岗+地库口+电动车棚+儿童游乐+健身+垃圾分类亭），小区间夹幼儿园与社区公园
- [x] **D 文化体育公园区**（约 8 公顷）：体育馆（大拱顶+前广场）、中央公园、图书馆、篮球场
- [x] **E 步行街商业带**：15m 宽，连通 CBD 与老城，两侧 2~3 层小体量商业，招牌墙最密
- [x] **F 滨江带**：宽 80m，滨江步道 + 江滩公园 + 酒店 + 观景台 + 摩天轮 + 渡轮码头

### 2.1 中山路与人民大道之间

- [x] 明确：两条主干道间距 350m，中间被次干道切成 4 块、支路切成约 16 个街区
- [x] **交叉口是城市原点**，地下为地铁换乘站，四个街角分工：

| 街角 | 内容 |
|---|---|
| 东南角 | **城市门户**：商场（负一层大卖场）+ 1 栋 100m 写字楼 + 下沉广场 + 地铁口 |
| 东北角 | 中央公园西入口（从商圈直接走进绿地） |
| 西南角 | 老城边界：6 层砖楼 + 沿街小店 + 巷口，与商场形成强对比 |
| 西北角 | 片区级商业：社区超市 + 餐饮街 + 银行 + 药店 |

- [ ] 全城通用规则：**由外向内密度递减**（交叉口=商业，往里一格=餐饮服务，再往里=办公居住与后巷）

### 2.2 高度规则：突变，不渐变

| 区域 | 限高 |
|---|---|
| 老城区 | **24m 硬上限** |
| 新住宅 | 60~100m（成组，同组同高） |
| CBD | 120~180m，允许 1 栋 200m 地标 |
| 滨江 | 60m（保留看江视线通廊） |
| 步行街 / 老城边界 | 12m（低层过渡，抬头能看到天） |

- [x] 老城 → CBD **不设过渡带**，一刀切

## 4. 进入系统

### 4.1 三级门语法

| 级别 | 视觉信号 | 行为 |
|---|---|---|
| **A 可进入** | 地面光斑 + 门内溢光 + 门头亮灯 + 地垫 + 雨棚 | 靠近提示 + 门框高亮 → **E 进入** |
| **B 浅进入** | 门内溢光较弱，无地垫 | 可走到门口 1~2m，看见内景 |
| **C 不可进入** | 卷帘门拉下 / 门禁红灯 / 铁栅门 | 靠近提示（已闭店 / 需要门卡 / 请走正门），**不给 E** |

- [x] 可进入门口统一光效（沿用现有）
- [x] 靠近才出提示，按 E 进入
- [x] **绝不给「按了没反应」的门**：打不开必须提前在视觉上说明
- [x] A 级入口额外信号：门内可见 NPC、地垫、突出招牌、更亮的门头
- [ ] 住宅进不去但单元门做**门禁交互**（“需要门卡 / 呼叫住户”），不要一堵白墙
- [x] 住宅上部 / 写字楼上部窗用**贴图式内景**（亮房间、窗帘、电视蓝光、人影）

### 4.2 门斗缓冲（配合「靠近才加载」）

- [x] 所有可进入空间是**封闭盒子**，外墙不开「能看到内部深处的洞」
- [ ] 入口向内退 **1.5~2m** 作门斗，作为加载缓冲
- [ ] B 级内景：门内 2~3m 真几何 + 更深处用雾/暗部收掉

## 5. 认领规则

- [ ] **只限住宅**：新小区塔楼/板楼、老住宅楼、公寓
