# 线性超级城市 · 世界基础设定（阶段一）

灵感来自 The Line，形态为：**双墙 + 中央城 + 墙外自然带的狭长人工岛**。

## 已定尺度

| 项 | 决策 |
|---|---|
| 城内净宽 | **5 km** |
| 城墙厚 / 高 | **300 m / 550 m**（阶段一） |
| 墙顶默认 | **外缘车道、内侧水道** |
| 墙外自然带 | 宽度随段起伏 |
| 样板段长 | **5 km**（宽度仍 5 km 城内净宽） |
| 水系 | 外海 → 水闸 → 城内河网；中央为景观河，非全程大江 |

## 入口

`linear.html` → `linear/main.js`

## 模块

| 文件 | 职责 |
|---|---|

## 与建筑风格规范的关系

建筑生成遵守 [`08-building-style.md`](./08-building-style.md)，但本场景是 **5 km 合批城市**，实现方式做了尺度适配：

| 08 铁律 | linear 落地方式 |
|---|---|
| A 1:1 尺寸 | shader + `dressFacade` 层高 3.0（住宅）/ 3.6（办公）；门 2.1；橱窗 2.8；开间 4.2~6.0 |
| B 高楼大堂 | `dressLobby`：挑高 5.4、雨棚 2.5~4、自动门 1.6、柱墩、门头楼名牌 |
| C 店铺内景 | `dressShopfront`：转角店做相邻两面；橱窗后货架/柜台/货品 + 吊顶灯板 + 重点陈列灯片；**不做**可走进去的店内几何（合批实例预算不够） |
| 暖色立面 | `WALL` / `WALL_WARM` / `PODIUM` 米黄石材系；玻璃 `#7d8f9c` 偏暗保证墙窗对比 |
| punch/inset | punch 开洞 ≈ 开间 60%×层高 56%；幕墙 punch≥0.85；几何窗台挑出产生阴影 |
| 立面层次 | `dressFacade` 做两条长边下段真窗洞；`pushBuilding` 加檐口 + 女儿墙；近楼加转角壁柱、落水管、空调机 |
| 夜景 | `N` 切换昼夜：天空球/星星/月光 + shader 亮窗 + 招牌/橱窗/店内自发光 + 路灯与车灯 |

入口仍是 `linear.html` → `linear/main.js`；主改动在 `linear/buildings.js`、`linear/mat.js`、`linear/light.js`、`linear/street.js`。
