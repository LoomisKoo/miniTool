## 1. 三条核心决策

### 决策 A：宠物不存像素，存「配方」

一只宠物 = 约 40 字节的 JSON，不是一张图。启动时把**图鉴蓝图**光栅化成一张图集。

- 图鉴条目 **120** 个蓝图 × 8 帧 = 960 个 64×64 单元 → **一张 2048² 图集**
- 每只宠物的**独立配色**由调色板 uniform / 实例属性提供，不额外占显存
- 组合空间 `体型8 × 耳6 × 尾6 × 眼5 × 花纹8 × 配色12 ≈ 13 万种`，图鉴之外的组合当作野生变种

> 关键点：**蓝图数量必须有上限**（图集容量），宠物数量没有上限（配色是免费的）。

### 决策 B：野生与领养用「项圈 + 行为」区分，不用图标

三段距离各给一个信号，任何一段单独都能看懂：

| 距离 | 信号 | 实现 |
|---|---|---|
| >20m | 剪影 | 无项圈、饱和度 −35%、体型 ×0.92 |
| 3–20m | 行为 | 野生会退开两步再回头；领养会迎上来 |
| <3m | 文本 | `野生 · 圆耳团子` / `豆豆 · 属于 @某人` |

唯一真值是 `ownerId`。昵称、项圈、home 全是派生结果，**不准再加 `isWild` 字段**。

### 决策 C：钓鱼不用固定钓场，用「任意岸边 + 吸附最近合法钓位」

用户问的是「岸边按 E」还是「固定钓场」。答案是**两者都要，但玩家只感知到一个**：

- 玩家在任意岸边按 E → 无需精确站位
- 系统吸附到**预计算的合法岸线钓点**（离水 <4m、前方是水、背后 12m 内有路）
- 工程上是有限点集（可调、可测、可做视觉摆放），体验上是自由的

**船是第二种入口**：码头有停泊的船，按 E 上船 → 船可沿水路缓慢移动到离岸 >15m 的深水区 → 在船上抛竿。深水区出稀有鱼，形成「岸钓 → 船钓」的进阶，也让船不只是装饰。

> 明确否决：不做自由抛竿（不规则岸线判定会失控）、不做钓鱼专用镜头（iso 视角切镜头很突兀）。

## 2. 开发顺序（每个里程碑独立可验收）

| 里程碑 | 交付 | 验收标准 |
|---|---|---|
| **M0** ✅ 引擎 | 配方类型 + Canvas 光栅化 + 图集打包 + 预览页 | 改一个参数，预览页的宠物立刻变；导出图集 ≤ 2048² |
| **M1** ✅ 街上有宠物 | 12 只野生宠物 + 确定性漫游 + 合批渲染 | 街上同时 12 只，2 次 draw call，帧率无变化 |
| **M2** 领养闭环 | 野生池轮换 + E 领养 + 服务端 CAS + 我的宠物 | 两个人抢同一只，只有一个成功，另一个收到提示 |
| **M3** 留存 | 每日口粮 + 饱腹度 + 门口便利贴 | 饱腹度低的宠物缩在门口；留言在楼下可见，主人回城才收到 |
| **M4** 图鉴 UI | 卡片网格 + 稀有度 + 我的记录 | 图鉴能翻 120 条，未获得的剪影为问号 |
| **M5** 钓鱼 | 岸钓点 + 四段玩法 + 鱼图鉴 + 船钓 | 从岸边按 E 能完整钓上一条鱼并进图鉴 |

依赖：M1 依赖 M0；M2 依赖 M1；M5 依赖 M0 + M4 的卡片组件。

## 3. 明确不做

- **不给整座城市套像素滤镜**。像素只出现在宠物/鱼的贴图与 UI 卡片上，写实城市保持不变。
- **不做实时位置同步**。所有移动都是 `seeded()` 算出来的，服务端只存归属与事件。
- **不做宠物战斗 / 繁育 / 交易**。这一期只做「遇见 → 领养 → 被看见 → 被投喂」。
- **不做自由抛竿与钓鱼镜头**。
- **不按性别做玩法分流**。宠物是异步社交，钓鱼是同步独处，两条线并列，玩家自选。

## 4. 视觉与 UI 基调（参考 PokéBonk）

首页那种「超大圆角 + 极粗字重 + 单主按钮」的做法可以直接搬：

- 圆角 `16–20px`，主要按钮 `radius 999px`
- 字重 800/900，标题字号不小于 28px
- **一层只放一件事**：城里只留一个主行动按钮，点开才展开
- 图鉴卡片固定 `aspect-ratio: 1 / 1`，宠物在该比例下居中，稀有度用**边框色**而不是角标

## 5. 风险

| 风险 | 处置 |
|---|---|
| 光栅化阻塞首屏（960 个单元约 4M 像素写入） | 分帧生成（每帧 ≤120 个单元），或放进 Worker + OffscreenCanvas |
| 野生宠物堆积 | 池化 + **按小时切片的确定性轮换**，全局上限 12 只 |
| 像素精灵在写实城市里像贴纸 | 采样用 `NearestFilter` 放大 + `LinearMipmapLinear` 缩小；加硬边描边 + 球形接触阴影；世界高度固定 0.6m |
| 留言变成骚扰渠道 | 留言**贴在门口**而非私信；复用现有 300 字 + `clean()` + 举报；同一用户对同一宠物每日 1 条 |
| 领养并发 | 服务端单次 compare-and-swap：`ownerId: null → userId` |
