# 08 · 建筑风格与生成规范（后续扩展必读）

本文是 `block/` 街区 Demo 的建筑设计基线。新增任何一栋楼、任何一家店，都按本文执行；
与代码不一致处以本文为准，然后改代码或改本文，**不允许两套标准并存**。

## 0. 三条铁律（不可讨论）

### 铁律 A：一切 1:1，按现实米制建模

没有"示意尺寸"。所有尺寸必须能对上现实规范，否则一眼读成模型。
直接引用下表，**不要临场估算**。

| 对象 | 现实尺寸 | 本工程取值 |
|---|---|---|
| 住宅层高 | 2.9~3.1m | 3.0 |
| 办公层高 | 3.6~4.2m | 3.6~4.0 |
| 商业层高（单层店面） | 4.5~6.0m | 店面净高 2.8~3.0，结构层 4.2 |
| 楼板结构层 | 0.30~0.40m | 0.30 |
| 标准开间 | 3.6 / 4.2 / 6.0 / 8.4m | 按立面 `bays` 取 3.6~8.4 |
| 窗台高 | 0.90m | 0.90 |
| 住宅窗高 | 1.50m | 1.50 |
| 幕墙层间梁（spandrel） | 0.80~1.00m | 0.8~1.0 |
| 单扇门 | 0.90 × 2.10m | 0.90 × 2.10 |
| 双扇门 / 自动门 | 1.50~1.80 × 2.20m | 1.60 × 2.20 |
| 旋转门 | 直径 1.8~2.2m，高 2.4m | 2.0 × 2.40 |
| 店门（带门套） | 宽 1.1~1.6m，高 2.4m | 1.3 × 2.4 |
| 店面橱窗玻璃 | 高 2.6~3.2m | 2.8~3.0 |
| 招牌底边离地 | ≥ 2.6m | 2.8 |
| 挑出式招牌 | 挑出 ≤ 1.2m | 1.0~1.2 |
| 人行道 | 3.0~5.0m | 4.0 |
| 机动车道 | 3.25~3.5m / 车道 | 3.4 |
| 停车位 | 2.5 × 5.3m | 2.5 × 5.3 |
| 女儿墙 | 1.0~1.2m | 1.0 |
| 台阶（室外） | 踢面 0.15、踏面 0.30 | 2 级，共 0.30 |
| 电梯井 | 2.4 × 2.4m，门宽 1.1m | 同 |
| 楼梯梯段宽 | ≥ 1.2m | 1.2 |
| 大堂净高 | 4.5~6.4m（塔楼挑高） | 4.5~6.0 |
| 货架通道 | ≥ 0.9m | 1.0 |
| 收银台 | 长 2.4~3.6m，高 1.0m | 2.8 × 1.0 |

判断方法：把任何一栋楼的门、窗、人（1.7m 视线）、车（1.5m 高）并排放，
**四者必须能同时成立**。门比车高、窗比人矮、招牌低于 2.6m 都是错的。

### 铁律 B：高楼必须有 1 楼大堂

凡是"塔楼 + 裙楼"或"10 层以上的独立塔"，底层**必须**是大堂（或大堂 + 商铺），
不能是一整面玻璃、也不能是空白实墙。

最低配置（缺一项就不算大堂）：

| 项 | 规格 |
|---|---|
| 挑高 | 净高 ≥ 4.5m（塔楼核心筒旁 5.4~6.4m） |
| 入口 | 自动门 1.6m 或旋转门 2.0m + 两侧固定玻璃 |
| 雨棚 | 挑出 2.5~4.0m，下沿挂感应筒灯 |
| 地面 | 石材 600×600，入口 3m 内做门垫/落尘区 |
| 前台/保安台 | 3.0~4.5m 长，高 1.15m，台后坐一人位置 |
| 电梯厅 | 2~6 台，梯门朝向大堂，门前留 2.0m 候梯区 |
| 信报箱墙 | 1.2m 高，嵌入侧墙 |
| 楼栋导视 | 楼层索引牌 1.8m 高 + 电梯侧壁按钮面板 |
| 吊顶 | 主灯槽 + 筒灯阵列（间距 2.4m），色温 4000K |
| 绿植/家具 | 至少一盆 1.5m 落地绿植 + 一组沙发或长凳 |

大堂**不做**的事：不放大屏幕广告墙（除非该楼定位为商业综合体）、
不放货架、不与楼上住宅共用同一套窗（大堂玻璃 ≥ 幕墙玻璃，且独立门套）。

### 铁律 C：店铺必须有符合类型的完整内景

店面不是"玻璃 + 几排色块"。凡是 1 楼有招牌的店，**门内必须是一间能认出来的店**：

- 内容必须**对口**：书店有书架与分类牌，药店有处方柜台与百子柜，面馆有煮面炉与吧台。
  放错内容比空着更糟（书店里摆饮料冷柜 = 一眼假）。
- 深度按现实：小店 3.5~4.5m，便利店 5.5~7.0m，面馆 6~8m。
- 门内 1.2m 必须空（动线），收银台距门 2.0~4.0m，货架通道 ≥ 0.9m。
- 光：天花板灯带 + 货架顶端灯，店内必须比店外亮；夜间靠 `glowMat` 自发光提亮，
  **不允许店内比街上暗**。
- 细节密度：**至少 6 个可辨认的构件组**（见 §5 各类型清单），每类店的"标志物"必须出现。

## 1. 四层架构（新增楼按层填，不许越层）

| 层 | 含义 | 代码落点 | 典型参数 |
|---|---|---|---|
| **L0 体量原型** | 这栋楼属于哪一族：收分 / 板楼 / 点式 / 围合 / 幕墙塔 | `families.js` 的生成器 | `W, D, floors, FH, shrink, corners` |
| **L1 立面语法** | 墙与窗的关系：幕墙 or 开洞，层间带，壁柱 | `wallFace({...})` | `punch, inset, fin, lit, bays` |
| **L2 构件字典** | 窗台、窗楣、雨棚、女儿墙、空调机、卷帘门、分缝 | `roofKit / clad / louver / downpipe / awning / shopFront` | 尺寸见 §0 |
| **L3 扰动层** | 每栋楼的差异：亮灯率、窗帘、招牌文案、店内商品 | `seed` 随机 + `shopInterior` 参数 | `seed, lit, goods` |

原则：**L0 定基调，L3 生差异**。不要靠改 L0 来做"不同"，那会破坏族的可读性；
差异应来自 L3（招牌、商品、亮灯、窗帘、空调机数量、屋顶物件）。

## 3. 立面语法（L1）：`wallFace` 参数表

```js
wallFace(parent, {
  along: 'x' | 'z', at: 墙面位置（±深度/2）,  cx, cz,
  w: 立面宽度, h: 立面高度, floors, bays,
  sign: +1 | -1,           // 外法线方向
  glass, warm, shade, metal, band,   // 五套材质（通常来自 WIN / alum / band）
  punch, inset,            // ★ 决定"幕墙"还是"开洞"
  lit,                     // 夜间亮灯率
  fin,                     // 竖向壁柱外挑
  seed,                    // 差异种子
})
```

| 类型 | `punch` | `inset` | 适用 |
|---|---|---|---|
| 玻璃幕墙 | 0.85~0.90 | 0.06~0.08 | CBD 塔楼、玻璃塔 |
| 半幕墙 / 带窗 | 0.72~0.80 | 0.10~0.14 | 现代办公 |
| **实墙开洞** | **0.56~0.72** | **0.14~0.20** | 石材办公楼、住宅、老楼 |

规则：

1. `punch ≥ 0.85` 触发幕墙分支（窗高 0.76FH）；否则开洞分支（窗高 0.56FH，窗台抬到 0.54FH）。
2. **玻璃必须真的退进墙面**：`inset ≥ 0.14` 时会产生窗洞侧壁与过梁，阴影由几何产生，
   这是"贴纸感"与"真窗"的唯一分界线。
3. `lit` 按类型：办公 0.55~0.65、住宅 0.5~0.6、酒店 0.7~0.8。
4. `fin` 壁柱：石材楼 0.40~0.46，塔楼 0.18~0.32，过大会挡住窗。
5. 层间带：幕墙做 28% 层高；开洞式压在窗台以下（12% 带 + 24% 窗台墙），
   都要挑出墙面 2~5.5cm 并加一道滴水线。
6. 每面至少 `bays ≥ 3`；开间宽度落在 3.6~8.4m。

## 4. 大堂规范（铁律 B 的实现清单）

### 4.1 面积与位置

| 楼型 | 大堂面积 | 位置 |
|---|---|---|
| 塔楼（≥20 层） | ≥ 120m² | 面向主街，占裙楼一层 40~60% |
| 中高层（10~20 层） | 60~100m² | 面向主街正中 |
| 板楼住宅 | 门厅 25~40m² | 单元入口，可含信报箱 + 门卫 |

### 4.2 必须构件

- [ ] 挑高空间（净高 ≥ 4.5m），无吊顶压低
- [ ] 入口自动门 / 旋转门 + 两侧固定玻璃 + 不锈钢门套
- [ ] 入口雨棚（挑出 2.5~4m），下沿 3 盏筒灯（夜间亮）
- [ ] 落尘门垫（1.8 × 3.0m）
- [ ] 前台 / 保安台（3.0~4.5m，高 1.15m）+ 台后椅 + 台面电话/屏
- [ ] 电梯厅：电梯数量 = `ceil(层数 / 6)`，门上留 2.0m 候梯区
- [ ] 楼层索引牌（1.8m 高，靠电梯侧墙）
- [ ] 信报箱墙（1.2m 高，嵌入侧墙）
- [ ] 吊顶灯槽 + 筒灯阵列（间距 2.4m，色温 4000K）
- [ ] 落地绿植 ≥ 1（1.5m）+ 沙发/长凳一组
- [ ] 门禁闸机（写字楼）/ 快递柜（住宅）

### 4.3 材质语言

石材地面（浅暖灰，600 模数）+ 石材或铝板墙面 + 深色金属门套 + 玻璃栏板（如有中庭）。
**大堂不用外墙那套色**：外墙米黄，大堂可以用同色系但更浅一档（明度 +0.06），
让人一进门有"进室内了"的明暗与材质转换。

### 4.4 代码落点

大堂是**独立的内景容器**，不要用一块玻璃 plane 假装：

1. 裙楼一层用 `cutFront()` 切出真实开口（进深 ≥ 5m）；
2. 内部用与 `shopInterior` 同级的构件拼装（地面、侧墙、吊顶、前台、绿植、灯槽）；
3. 入口用 `shopFront()` 变体（去掉菜单板与门头射灯的餐饮化处理，换成门套 + 雨棚）；
4. 门前 `solid()` 注册，保证行人不会穿进玻璃。

## 5. 店铺内景规范（铁律 C 的实现清单）

### 5.1 通用参数

```js
shopInterior(g, {
  w,           // 店面宽度（内净）
  zFront,      // 玻璃所在 z
  depth,       // 进深：小店 3.5~4.5，便利店 5.5~7.0，餐饮 6~8
  h,           // 净高：2.8~3.0（店面），3.6~4.2（大型店）
  kind,        // 'shop' | 'books' | 'pharmacy' | 后续扩展
  floor, back, side,      // 地 / 后墙 / 侧墙色
  counter, island,        // 收银台、中岛
  goods,       // 商品配色组
  seed,
})
```

通用硬规则：

- 门内 1.2m 空；收银台距门 2.0~4.0m；主通道 ≥ 0.9m。
- 货架背板离后墙 0.05~0.1m，不留穿帮缝。
- 商品全部进 `InstancedMesh`（`scatter`），不许一件一个 mesh。
- 顶部灯带 + 货架顶灯，店内亮度 > 店外（夜间差 ≥ 1 档）。
- 招牌与店内主题一致（文字、配色、商品类型）。

### 5.2 各类店铺"必须出现"的清单

> 每条至少实现 6 项，加粗的是该类型的**标志物**（缺了就不像）。

#### 便利店（`kind: 'shop'`）

**收银台（POS 机 + 价签灯带 + 关东煮锅 + 烟柜）**、**立式冷柜 3~4 门（饮料）**、
**冰淇淋卧柜**、中央货架 4~6 排 × 4 层（零食/日用/文具）、端架（促销堆头）、
热食柜（包子机 / 微波炉）、咖啡机、杂志架、快递取件柜、门内伞桶、地贴导向。

#### 药店 / 药妆（`kind: 'pharmacy'`）

**处方柜台（L 形 + 半高隔断 + 客椅）**、**中药百子柜（成排小抽屉 + 拉手 + 标签）**、
OTC 开架 3~5 排（分感冒/肠胃/外用/妇幼）、**冷藏药品柜（玻璃门 + 蓝光）**、
血压/血糖测量台、收银台、促销堆头、健康宣教立牌、坐诊隔间（拉帘）。

#### 书店 / 文具（`kind: 'books'`）

**顶天书架墙（2.2m 高 × 0.3m 深，留分类牌）**、**平台展台（新书 / 推荐 / 封面朝外）**、
分类吊牌（文学/社科/童书/教辅）、阅读区（沙发 + 小桌 + 落地灯）、文创文具柜、
收银台（可兼咖啡）、书梯（滚动式）、店内海报。

#### 面馆 / 拉面（`kind: 'shop'`）

**开放式厨房（煮面炉 + 汤锅 + 抽油烟罩）**、**吧台 8~12 座（带调味盒/纸巾/水壶）**、
出餐窗口、**菜单木牌墙或灯箱**、筷筒/辣油/醋、四人桌 2~4 张、地面防滑砖、蒸汽感（雾面玻璃）。

#### 居酒屋

**吧台 + 吊灯（暖 2700K）**、**酒瓶墙（背光）**、炭火烤炉 + 排烟管、暖帘、
提灯（门口红灯笼）、单个包间（推拉门 + 矮桌）、黑板菜单。

#### 洗衣店

**投币洗衣机 6~10 台 + 滚筒烘干机 3~4 台（成排、正面朝外）**、折叠台、
洗衣液自动售货机、等候椅 + 小桌 + 杂志、价格告示板、地面防滑。

#### 奶茶 / 咖啡

**操作台（封口机 / 制冰机 / 糖浆架）**、**取餐窗口 + 菜单灯箱**、
冷柜（备料）、小吧台或站立桌、外带区、咖啡店另加意式机 + 磨豆机 + 展示柜 + 黑板菜单。

#### 理发店

**镜台 3~4 工位（镜 + 台 + 椅 + 工具车）**、**洗头椅 2 台 + 洗头盆**、
候客沙发 + 杂志、产品柜（洗护）、地面瓷砖、暖光筒灯。

#### 菜市场（摊位制）

分格摊位（蔬菜 / 肉 / 水产 / 熟食）、**案板 + 电子秤 + 吊灯罩**、
水产冰台 + 水槽 + 排水沟、菜筐堆叠、手写价签牌、通道 ≥ 2.0m。

### 5.3 不允许

- 店内一片空、只有地墙天花（"毛坯店"）；
- 商品斜放 / 货架倾斜（`scatter` 的 rotation 必须为 0 或按墙法线旋转）；
- 店内比店外暗；
- 后墙穿帮（能看到建筑外部）；
- 用一块贴图假装货架。

## 6. 材质与调色铁律

1. **一栋楼一种主材色**。`harmonizePalette(root)` 会取面积最大的色簇做锚点，
   其余中性材质归到同色相，明度吸附到 `A, A-0.085, A-0.17, A-0.28, A-0.40, A+0.06`。
   **不要手写墙面色**，写进去也会被归纳掉。
2. **暖色为主**（真实城市立面）：

```
米黄石材 H36 S0.20   浅砂 H30 S0.17   奶油 H44 S0.19
赭石面砖 H22 S0.22   灰米 H50 S0.15   陶土 H17 S0.20
暖白 H41 S0.16       沙岩 H33 S0.18
```

   冷色只给玻璃幕墙（S 0.12~0.17），城市里保留 20~25% 的玻璃塔即可。
3. **窗玻璃全场一套**：`#7d8f9c` / metal 0.26 / rough 0.22 / env 0.70。
   普通窗、窗帘、夜间亮灯三态共用同一色值，只有 `emissive` 区分 —— 白天必须完全一致。
4. **金属度封顶 0.45**、粗糙度下限 0.34。超过 0.45 时颜色不起作用，只剩环境反射，必灰。
5. **不允许纯白立面**。`std()` 对 sRGB > 0.58 做软拐点压缩；反照率上限 0.78。
   带 `map` 的颜色只当乘数，写 `#ffffff`。
6. **发光材质走 `glowMat` / `trackGlow`**，昼夜强度两端给出，进 `applyNight` 统一插值。
7. **贴地贴片**（光斑、光带）用 `trackFade` 让白天全透明，并用 `clipRect` 裁到楼体之外。

## 7. 性能预算

| 项 | 上限 | 做法 |
|---|---|---|
| 单栋 mesh 数 | ≤ 60 | 同类构件进 `InstancedMesh` |

## 8. 新增一栋楼的最小清单

- [ ] 选 L0 族，或新写一个生成器（同族参数化即可，不要复制粘贴改数值）
- [ ] 定 `W / D / floors / FH`，与 §0 尺寸表对齐
- [ ] 四面 `wallFace`，按类型给 `punch / inset / lit / fin / bays`
- [ ] 底层：塔楼 → **大堂**（§4）；沿街 → **店铺内景 + 招牌**（§5）
- [ ] `roofKit` + `clad` 石材分缝 + 至少一个 L2 构件（空调机 / 晾衣杆 / 女儿墙压顶 / 雨棚）
- [ ] `solid()` 注册碰撞体（含裙楼、挑檐、门前台阶）
- [ ] `site.js` 的 pad 表加地坪，保证地面与人行道对得上
- [ ] 跑 `node block/chk.mjs`：`fixZfight` 不动、埋窗数为 0
- [ ] 色板交给 `harmonizePalette`，**不自写墙色**
- [ ] 夜景自检：窗有亮有暗、店内比店外亮、大堂灯亮

## 9. 验收口径（本 Demo 的"好看"标准）

一栋楼算通过，需要同时满足：

1. **尺度**：门 2.1m / 层 3.0~3.6m / 窗台 0.9m，与人和车同框不违和。
2. **立面**：实墙面积 ≥ 40%，窗洞有 ≥ 14cm 进深阴影，楼层有 ≥ 3 道横向分隔。
3. **颜色**：单栋只有一种主材色系；整城暖色为主，玻璃塔作冷色点缀。
4. **底层**：塔楼有大堂、沿街店有对口的完整内景。
5. **屋顶**：有女儿墙 / 设备 / 压顶，不是一块白板。
6. **夜景**：亮灯率对、店内明亮、发光物不爆亮、贴地不出黑斑。
7. **稳定**：无共面闪烁、无窗户穿模、无货架倾斜。
