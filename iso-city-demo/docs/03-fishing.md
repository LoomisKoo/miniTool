## 1. 为什么不做固定钓场

用户问的是「岸边按 E」还是「固定钓场」。答案是：**玩家感知为任意岸边，工程上是有限点集**。

| 方案 | 问题 |
|---|---|
| 完全自由抛竿 | 不规则岸线判定失控；可能对着马路/墙抛；相机取景不可控 |
| 固定钓场 | 「城市里随便走」的自由感没了；18 处水体只能开 2 个，其他地方明明有岸却钓不了 |
| **吸附钓位（采用）** | 岸线预先采样成合法点集，玩家在任意岸边按 E，吸附到最近的一个 |

体验上是自由的，工程上是可测的。抛竿方向由钓位的**法线**决定，所以永远朝水面。

## 2. 钓位数据

### 2.1 生成（构建期，非运行时）

新增 `tools/gen-fishing.mjs`，读 `src/data/osm-city.json`，输出 `src/data/fishing.json`：

```
对每个 water 多边形的每条边：
  沿边每 2m 采样一个点 P
  取边法线 N（指向多边形外部）
  若 P + N*1.5m 落在其他水体内部 → N 取反        // 保证 N 指向陆地
  否则 N 就是「陆地方向」，抛竿方向 = -N
  
  合法性：
    P 不在任何 building 的 AABB 内（外扩 0.5m）
    P 到最近道路折线距离 < 12m                    // 玩家能走到
    P 到最近建筑外墙 > 1.2m                       // 不卡在墙里
  去重：与已有点距离 < 6m 的丢弃
```

输出：

```json
{
  "spots": [
    { "x": -42.5, "z": 88.2, "nx": -0.83, "nz": 0.55, "water": 3 }
  ],
  "docks": [
    { "x": -58.0, "z": 91.0, "nx": 0.9, "nz": -0.42, "water": 3, "boat": "b1" }
  ],
  "deep": [
    { "x": -70.0, "z": 96.0, "water": 3, "r": 9 }
  ]
}
```

- `spots`：岸钓点，预计 200~400 个
- `docks`：码头，**手动挑 3~4 个**位置好的点（有船、有木栈道、有路灯）
- `deep`：深水区圆心（`water` 多边形内切圆心，离岸 >15m），船钓用

> 码头不要自动生成。船是视觉资产，位置必须手挑，否则船会卡在怪地方。

### 2.2 吸附

```ts
// src/fishing/spots.ts
export function nearestSpot(pos: Vec2, maxDist = 5) {
  let best = null
  for (const s of SPOTS) {
    const d = Math.hypot(pos.x - s.x, pos.z - s.z)
    if (d < maxDist && (!best || d < best.d)) best = { ...s, d }
  }
  return best
}
```

玩家按 E 时：

1. 若已上船 → 直接抛竿
2. 否则取 `nearestSpot`；有结果 → **玩家瞬移到钓位上**（1.5m 内不瞬移，只转向），面朝 `-N`
3. 无结果 → 不提示（避免「明明站岸边却没反应」的困惑，改成宽容半径 5m）

## 3. 玩法状态机

单键操作。E 启动，之后全程只需一个键（或鼠标左键）。

```
idle ──E──> cast(0.45s 抛物线) ──> wait ──随机 1.5~6s──> bite(0.4s 窗口)
                                    │                        │
                                    └── 假咬(抖一下) ────────┘
                                                             │ 命中
                                                             ▼
                                                          reel
                                                    ┌────────┴────────┐
                                              进度满 3s            断线/脱钩
                                                    ▼                 ▼
                                                  landed            fail
```

### 3.1 各阶段规格

| 阶段 | 时长 | 输入 | 失败 |
|---|---|---|---|
| `cast` | 0.45s | 无 | 无 |
| `wait` | 1.5~6s 随机 | 点太早 = 空钩 | 提前收线 → 直接 idle |
| `bite` | **0.40s**（稀有鱼 0.30s） | 点击一次 | 超时 → `fail`，鱼跑了 |
| `reel` | 需累计 3.0s | **按住** 升高张力 | 张力 >100 断线；张力 =0 持续 1s 脱钩 |

### 3.2 张力条

```
张力  ▏        ▓▓▓▓▓▓        ▏
      0        绿区(22%)     100
      ▲ 当前张力，按住 +80/s，松开 -110/s
```

- 绿区中心随正弦漂移：`center = 50 + sin(t * 1.1) * 18`
- 稀有度越高，绿区越窄（普通 26%、少见 20%、稀有 15%、传说 11%）
- 鱼挣扎（每 1.2s 一次）：绿区瞬间跳 ±15%
- 进度只在张力落在绿区时累加

**这套参数的意义**：没有一次失败是不可理解的（掉出去是因为你没跟上漂移），也没有一次成功是靠运气（3 秒内持续跟住）。

### 3.3 视觉

| 元素 | 实现 |
|---|---|
| 钓竿 | 一根 0.03m 的圆柱，从玩家手部斜向上 35° |
| 鱼线 | `Line`，从竿尖到浮标，**两段贝塞尔**（下垂感） |
| 浮标 | 0.12m 小球，红白两色，随水面正弦 ±0.06m |
| 涟漪 | 复用 `GlowDisc`，浮标下方一圈扩散环 |
| 咬钩提示 | 浮标下沉 0.25m + 屏幕底部一个字（不是感叹号图标） |

**不做钓鱼专用镜头。** iso 视角下鱼在 5~8m 外，屏幕内可见；切镜头会打断「我在城市里」的连续感。

抛竿距离：`5 + rand * 2.5` 米，方向 = 钓位法线反方向。

## 4. 鱼

### 4.1 数据

```ts
export type FishSpecies = {
  id: string
  name: string
  recipe: FishRecipe
  palette: Palette
  rarity: 'common' | 'uncommon' | 'rare' | 'legend'
  water: Array<'river' | 'lake' | 'harbor'>   // 出现在哪类水体
  deep: boolean                                // 是否只在深水区
  hour?: [number, number]                      // 出现时段，如 [19, 4] = 夜行
  kg: [number, number]                         // 重量区间
}
```

预计 `240` 种。图鉴一条 = 精灵 + 名称 + 重量纪录。

### 4.2 抽取

```ts
function rollFish(spot, deep, hour) {
  const pool = SPECIES.filter(
    (f) => f.water.includes(spot.kind) && (!f.deep || deep) && inHour(f.hour, hour),
  )
  const weights = { common: 60, uncommon: 24, rare: 12, legend: 4 }
  // 深水区把稀有度整体上移一档
  ...
}
```

**夜晚加成**：`hour` 在 19~4 时，`rare`/`legend` 权重 ×2。这样夜钓（已经是夜间模式）有实际收益。

### 4.3 重量

真实钓鱼玩家的炫耀点是**重量**，不是数量。

```ts
// 对数正态：绝大多数是小鱼，偶尔一条大货
const kg = lo + Math.exp(gauss() * 0.45) * (hi - lo) * 0.32
```

记录三个数字，都存服务端：

- `personalBest`（我的纪录）
- `worldBest`（全城最大）
- `count`（钓到几次）

图鉴显示：`我的 3.2kg · 全城 7.8kg @某人`

## 5. 船

### 5.1 形态

- 3~4 艘停泊船，位置来自 `fishing.json` 的 `docks`
- 造型：程序化（`LatheGeometry` 船体 + 一根桅杆 + 一块布），不用外部模型，几十行搞定
- 船在水面上下浮动：`y = 0.06 + sin(t * 0.9 + seed) * 0.05`，`rotation.z = sin(t * 0.7) * 0.03`

### 5.2 上船

```
岸边靠近船 3m → 显示「上船」→ E
上船后：
  - 玩家模型隐藏，相机跟随船
  - W/S 前后，A/D 转向（比走路慢 40%）
  - 只能在 water 多边形内移动（越界钳制到岸边）
  - E 抛竿，抛竿方向 = 船头方向
  - 离岸 >15m 时进入「深水」，稀有度上移
  - 再按 E（未抛竿时）下船，回到最近的 dock 点
```

**这是船唯一的存在理由：深水区才出稀有鱼。** 否则船就是装饰，玩家上去一次就不会再上去。

### 5.3 移动钳制

用 `water` 多边形做点在面内判断（`THREE.ShapeUtils.isPointInside` 或自写射线法）。船速慢（2.2m/s），每帧判断一次成本可忽略。

## 6. 与宠物联动的出口

钓鱼不能是孤立的：

1. **鱼可以喂宠物**：钓到的小鱼可作为口粮的替代品（`kg < 0.5` 的鱼 → 1 次投喂）。这样钓鱼玩家有东西可以送给宠物玩家。
2. **宠物会叼鱼回来**：主人 24h 没上线，宠物有概率叼回一条 `common` 鱼（写进图鉴，标注「豆豆叼回来的」）。这是宠物系统里最温暖的一条，成本极低。
3. **门口便利贴**可以写「你家的豆豆今天在码头看人钓鱼」。

## 9. 验收

**M5**
1. 在任意岸边按 E，玩家吸附到钓位并面朝水面
2. 完整走通 抛竿 → 等待 → 咬钩 → 收线 → 上钩
3. 提前点击是空钩，超时不点鱼跑了
4. 张力掉出绿区会脱钩，超上限会断线
5. 钓到的鱼进图鉴，重量记录正确，全城纪录能更新
6. 上船后能移动、能在深水区抛竿，稀有鱼概率明显更高
7. 一条 `<0.5kg` 的鱼可以喂宠物，宠物饱腹度上升
