# 风铃物语 · wind-chime

夜色庭院里的多节风铃小工具（three.js 3D · Web Audio 合成铃音/风声 · `assets/bgm.mp3` 循环 BGM · 纯离线）

声音开关同时控制：BGM、风声、敲击。

仓库根目录有跨项目 [发布总表](../README.md#发布总表)；此处只记本工具。

## 场景

仲夏夜庭院：月光 / 萤火两种夜空可切换，风铃悬于横杆；高路灯暖光与薄雾远影衬底。风会自己来——轻轻摇动铃管，发出细碎叮当。

## 结构（模拟真实风铃）

- 上节：3 颗小风铃，风里甩动时铃舌轻碰，发出清脆高音
- 下节：木质主盘 + 6 根长短渐变的金属长管
- 中央：黄铜撞锤 + 风叶（兜风摆起后敲打长管内壁，是主声源）
- 无发光部件、无固定旋律：所有声音都由“风 + 碰撞”的物理因果产生

## 玩法

- 有夜风路过：持续微风 + 偶发阵风，风铃自然作响
- 指尖划过 / 拨动 / 轻点管子：会留下几点微光星星与月牙，轻轻散落
- 在夜空上慢滑 = 亲手扇起微风
- 许愿：一句今夜温柔话 + 一串柔和风铃音

## 技术要点

- 音色 = 金属管非谐波泛音 + 指数衰减 + 卷积混响（纯合成零素材）
- 物理：横杆 + 竖串软绳摆动；阵风推动铃管相碰
- 打包产物约 1MB，`node build.mjs` 产出三端 zip

## 目录

- `src/audio.js` Web Audio 合成
- `src/fx.js` 夜色庭院 / 路灯光锥 / 柔和散落光点
- `src/app.js` 3D 风铃 / 物理 / 交互
- `build.mjs` → `dist/{平台}-wind-chime.zip`
