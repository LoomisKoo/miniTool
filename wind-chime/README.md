# 微风铃语 · wind-chime

仲夏夜窗边的多节风铃小工具（three.js 3D · Web Audio 全合成音效 · 纯离线）

## 场景

窗外仲夏夜：繁星 / 月光 / 萤火三种夜空可切换，木窗框与窗台围出窗景；风铃从窗楣悬下。风会自己来——轻轻摇动铃管、中央风叶，发出细碎叮当。

## 结构（模拟真实风铃）

- 上节：3 颗小风铃，风里甩动时铃舌轻碰，发出清脆高音
- 下节：木质主盘 + 6 根长短渐变的金属长管
- 中央：黄铜撞锤 + 风叶（兜风摆起后敲打长管内壁，是主声源）
- 无发光部件、无固定旋律：所有声音都由“风 + 碰撞”的物理因果产生

## 玩法

- 有夜风路过：持续微风 + 偶发阵风，风铃自然作响
- 指尖划过 / 拨动 / 轻点管子与小风铃：会留下几点微光星星与月牙，轻轻散落到窗台
- 在夜空上慢滑 = 亲手扇起微风
- 许愿：一句今夜温柔话 + 一串柔和风铃音

## 技术要点

- 10 档音色 = 3 小铃 + 6 长管，金属声 = 非谐波泛音 + 指数衰减 + 卷积混响（纯合成零素材）
- 物理：两节串联摆（上小盘 / 主盘）+ 长管、风叶、小铃各自独立摆动；阵风推动风叶去敲管
- 窗楣挂点每帧按 3D 投影回写，与 2D 木窗严丝合缝
- 打包产物约 1MB，`node build.mjs` 产出三端 zip

## 目录

- `src/audio.js` Web Audio 合成
- `src/fx.js` 仲夏夜窗景 / 柔和散落光点
- `src/app.js` 3D 风铃 / 物理 / 交互
- `build.mjs` → `dist/{平台}-wind-chime.zip`
