# 碎物间（shatter-room）

第一人称砸碎解压小游戏。Three.js 渲染 + cannon-es 物理。

## 操作

- 点击「开始发泄」锁定鼠标
- `WASD` 移动 · 鼠标瞄准 · 左键射击
- `R` / 右下角按钮：重置场景

## 开发

```bash
cd shatter-room
npm install
npm run dev
```
