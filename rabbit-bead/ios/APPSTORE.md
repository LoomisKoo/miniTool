```
把一张照片，变成真的能拼出来的拼豆图纸。
```

## 3. English (U.S.) — en-US

### Name (30)
```
RabbitBead: Fuse Bead Patterns
```
30 chars — **正好卡满上限**

**品牌是 `RabbitBead`，「: Fuse Bead Patterns」是描述语、不是品牌**——用来吃品类词的搜索权重，
因为 Name 的权重高于 Subtitle。审核指南 2.3.7 对名称里塞关键词有裁量；若被驳回，
退回纯 `RabbitBead`、把品类词全挪到 Subtitle 即可，其余文案不用动。

命名理由：`RabbitBead` = 兔（Rabbit）+ 拼豆（Bead），和中文名「兔格拼豆」对得上，
且自解释——新 App 挤在一堆成熟竞品中间时，「一眼看懂」比品牌独特性更值钱。
「格」不塞进英文名，改用 App 图标表达（一只由网格/像素豆拼成的兔子），中文名保留「格」。

**为什么描述语不是 `Bead Pattern`**：在英文里 `bead pattern` 主要指向**串珠编织/珠宝首饰**
（peyote stitch、brick stitch、织机串珠），是另一门手艺。证据见下方「术语核查」。

撞名核查（iTunes Search API，美区）：`BeadGrid`、`BeadPatternCreator` 已被占用；
`RabbitBead` / `RabbitGrid` / `BunnyGrid` 未发现同名。注意这只覆盖已上线名称，
最终以 ASC 建 App 时的判定为准；商标检索是另一件事（`RabbitBead` 是臆造组合，建议上架前去 USPTO 查一下）。

### 术语核查（决定英文命名的依据）

这门手艺在国外的叫法（分地区，别用错）：

| 语境 | 英文叫法 |
| --- | --- |
| 通用/行业正名 | **fuse beads**（也叫 iron beads、melty beads、thermobeads） |
| 美国 | **Perler beads**（品牌当通用名用，类似 Kleenex） |
| 英国 / 欧洲 | **Hama beads**（丹麦老牌） |
| 像素画社区 | **bead sprites**（r/beadsprites）、pixel beads |
| 日本 | アイロンビーズ / パーラービーズ |
| 成品图 | **pattern**（社区主流） |

`Bead Pattern` 单独用会落进错语义桶。美区搜索结果印证：`Beading Patterns & Tutorials`、

`Beads Creator - Bead Patterns`、`PixelBead`、`PerlerBead Pattern Maker`。

**`Perler` / `Hama` / `Artkal` 是他人商标，只进关键词，绝不进 Name / Subtitle。**
`Perler` 现属 Advantus Corp.（2025-09 收购），有美/台/马德里注册在案，放进应用名是
审核指南 5.2.1 的高风险区。

### Description (4000)
```
Turn a photo into a fuse bead pattern you can actually build.

Stop counting colors off a photo cell by cell. Pick an image and seconds later you get a
pattern with every code labeled and every bead counted. Everything runs on your device —
no network, no uploads, your photos never leave your iPhone or iPad.

■ PHOTO TO PATTERN
· Pick from Photos; match against the full MARD / COCO 291-color catalogs using perceptual
  (Oklab) color distance, not naive RGB nearest-match
· Sampling mode picks itself: dominant color for cartoons and illustrations so outlines
  survive, average color for photos so gradients stay smooth
· Neighbouring similar colors merge automatically to keep the pattern clean
· Adjustable bead width, board size, and color limit (8–80 colors)
· Floyd–Steinberg dithering for smoother photo gradients

■ CROP BEFORE YOU COMMIT
Ratios (original / 1:1 / 3:4 / 4:3 / 9:16 / 16:9 / free), pinch to zoom, 90° rotate, mirror;
in free mode drag the corner handles. Reopen the crop any time to tighten or widen it.

■ 2D AND 3D PREVIEW
· 2D: drag to pan, pinch to zoom, double-tap to zoom in or reset. Codes appear inside cells
  once you zoom in far enough; tap a cell to highlight its code
· 3D: every bead rendered as a real cylinder with a center hole. Drag to rotate, tilt and
  zoom to see how the finished piece will look before you build it

■ HAND CORRECTIONS
Brush, eraser, and color picker. Fix any cell the automatic result got wrong — paint fast
and strokes interpolate in half-cell steps so they never break. 60 steps of undo/redo.

one full image or one image per board.

The free version includes the full photo-to-pattern flow, previews, hand editing, and

full-size export without the signature line, background removal, and unlimited projects.
```
