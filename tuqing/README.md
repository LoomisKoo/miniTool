# 图轻（tuqing）

图片瘦身小工具：按目标体积自动压缩、防平台二次压缩。名字暂定（与「轻映」同系列：轻映切图 → 图轻瘦身）。

纯离线 Web 小工具（`index.html` + `app.js`，canvas 本地重编码，无外部依赖、无网络请求）。核心思路：**目标不是"越小越好"，而是"恰好低于平台二次压缩阈值、画质保留到最高"**——小红书笔记约 1MB 会被平台强制二次压缩导致画质劣化，图轻默认压到 ≤900KB 规避。图片全程本机处理不上传。

## 功能

- **处理目标（场景档位，主推）**
  - 小红书笔记：≤900KB、长边 ≤1440，防二次压缩
  - 微信表情头像：≤500KB、长边 ≤800
  - 高清画质：转 WebP 保细节，不设体积上限
  - 自定义：格式（自动/JPG/WebP/PNG）+ 质量滑块 + 最长边 + 目标体积「自动达标」
- **自动达标算法**：质量二分在小尺寸探针上求「≤ 目标体积的最高质量」，再全尺寸复核微调；仍不达标自动逐档降尺寸（PNG 无损时仅降尺寸）。比手动拖滑块省事，是相对 Squoosh/TinyPNG 的差异点
- 压缩后拖动对比原图/处理后，显示尺寸与节省百分比；原图已达标时提示直接使用原图
- 保存：小红书容器走 `xhs.miniTool` 存相册；其它容器回退大图预览 + 长按保存（桌面附下载）
- 格式自动决策：支持 WebP 编码则 WebP（体积最小），否则按原图是否透明选 PNG/JPG

## 目录

```
tuqing/
├── index.html          # 单屏页面（内嵌样式）
├── app.js              # 全部逻辑
├── platforms/          # 平台差异（现仅 config 元信息）
├── build.mjs           # 打包脚本

```

## 打包与本地预览

```bash
node build.mjs                # 全部平台
node build.mjs douyin         # 仅抖音
python3 -m http.server 9876   # 本地预览（浏览器拖图即可调试；无 xhs 容器时保存走预览/下载）
```

小红书审计：`node ../xiaohongshu/minitool-zip-builder/scripts/audit_artifact.mjs dist/xiaohongshu`

## 已知边界 / 后续可做

- 现为**单张**处理（多选时取首张）；批量逐张处理需加结果列表
- 不做比例裁切/宫格（那是「轻映」的活，产品边界刻意分开）
- EXIF 方向依赖 WebKit 自动纠正；HEIC 需容器 WebView 解码支持
- 大图先等比降到目标长边再编码，避免超 WebKit canvas 上限
